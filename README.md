# TDRepro: A Neurosymbolic Approach to Reproducing Timing-Dependent Flaky Test Failures

This README accompanies the artifact for the paper [TDRepro: A Neurosymbolic Approach to Reproducing Timing-Dependent Flaky Test Failures](https://people.cs.gmu.edu/~winglam/publications/2026/RahmanETAL26TDRepro.pdf).

This work introduces an approach to systematically reproducing timing-dependent flaky test failures by identifying and manipulating timing-related conditions that trigger intermittent failures. TDRepro combines neural and symbolic techniques to guide failure reproduction, reducing the reliance on repeated test executions.

The primary goal of this artifact is to provide the implementation of TDRepro, the experimental subjects, and the scripts needed to reproduce the experiments and evaluate its effectiveness in reproducing timing-dependent flaky test failures.

For Tdrepro: run `cd tdrepro/`
             run the other commands from the `tdrepro` dir
